# Licensing

**Dataset licence: PENDING OWNER RULING.** This marker records that no data licence has yet been
selected; it is not itself a licence grant. Until a licence is declared here, all rights in the
canonical data (`data/canonical`) and its compiled exports (`/api/*`) are reserved. Ask before
redistributing.

**Code licence:** likewise undeclared; all rights reserved until a `LICENSE` file exists at the
repository root.

Every `/api` export repeats this state in `meta.license` (`spdx: null`, `status:
"PENDING_OWNER_RULING"`). When a licence is chosen, this file, `meta.license.spdx`, `CITATION.cff`
and the repository `LICENSE` files change in one commit, and the dataset changelog records the
revision from which the licence applies.

Third-party material: the atlas cites published papers, reviews and books as evidence. Citation
records (`data/canonical/sources`) carry bibliographic data only; no source text is reproduced.
